# Glossary

→ [[Marketing]]

Words we use with clients, and what we mean by them, so every person and every session says the same thing.

| Term | Meaning |
|---|---|
| Retainer | A monthly engagement with a written scope, see [[Decision, Monthly Retainers Only]] |
| Open loop | Any promise not yet kept, tracked in the [[Open Loops Register]] |
| MOC | Map of content: a note that lists every note in a folder |
| Hub | One of the four nodes every note links to |
| Spinout | A standalone copy of one client's notes, see [[SOP, Spinning Out a Client Vault]] |

## Words we avoid

- Promises about outcomes. We promise work and reporting, never results.
- Vague adjectives in reports. A number or nothing.

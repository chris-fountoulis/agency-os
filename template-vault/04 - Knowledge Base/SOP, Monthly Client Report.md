# SOP, Monthly Client Report

→ [[Product]]

What every client receives in the first week of each month, and the checks before it is sent.

**Owner:** account manager · **Trigger:** first working day of the month · **Takes:** about an hour per client

## The report

1. One paragraph: what happened, in plain words.
2. Three numbers that match the client's goals, against last month.
3. What we change next month, and why.

## Before sending

- Every number traced to its source account. If two sources disagree, say which one the report uses.
- No claim the data does not support. "Improved" needs a number next to it.
- A person reads the whole draft, even when it was generated.

## After sending

- Add a history line to the client note with the date and the one paragraph summary.

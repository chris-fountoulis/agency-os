# SOP, Client Onboarding

→ [[Product]]

The first two weeks of every engagement, in order. Every new client goes through all of it, however small the retainer.

**Owner:** account manager · **Trigger:** signed agreement · **Takes:** about two weeks

## Steps

1. **Same day:** create the client note from the [[Client]] template, add it to the [[Clients MOC]], open a loop for the kickoff in the [[Open Loops Register]].
2. **Within three days:** kickoff call. Write the meeting note from the [[Meeting]] template the same day.
3. **Within a week:** collect access to every account the scope needs. Record *where* each credential lives, never its value.
4. **Within two weeks:** first deliverable or first report baseline, whichever the scope starts with.
5. **Close the loop:** move the kickoff row to Closed with the outcome.

## Done when

- The client note has goals, scope, key facts and a history line for each step.
- Every promise made on the kickoff call is a row in the [[Open Loops Register]].

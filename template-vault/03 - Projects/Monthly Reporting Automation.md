# Project: Monthly Reporting Automation

→ [[Management]]

Generate every client's monthly report draft automatically on the first working day, so account managers review instead of assemble.

**Owner:** Jonas · **Due:** 2026-11-30 · **Status:** building

## Goal

Every report in [[SOP, Monthly Client Report]] arrives as a draft with the numbers filled in. A person still reviews and sends it.

## Plan

1. Pull the numbers each report needs from the analytics and ads accounts.
2. Fill the report template and save the draft next to the client's other files.
3. Post a review task for the account manager.
